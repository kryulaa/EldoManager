G2G Edit Sniffer DEV TOOL

Captures G2G API calls — edits (PATCH/PUT/POST) and search/list (GET). Shows URL, params, headers, request body, and response.

Step 1 — Add bookmarklet

Drag the button to your Bookmarks Bar (Ctrl+Shift+B).

🔍 G2G Sniffer

Step 2 — Activate on the G2G search page

Go to g2g.com/categories/rbl-item?fa=b08c318c%3Aee1ed7d8&q=sea+dragon, open DevTools (F12) Console, paste the script and press Enter.

Step 3 — Reload the page

After activating the sniffer, reload the page. All sls.g2g.com requests will appear in the panel — look for 🔎 SEARCH entries (GET requests to offer/search or offer/list). Copy the full URL + params and share.
